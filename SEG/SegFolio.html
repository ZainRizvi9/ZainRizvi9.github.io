01 / About

Hey, I'm Zain.

Third year CS co-op at uOttawa. Most of my time goes toward building software, whether that's data pipelines, ML stuff, or full stack apps. Design is something I'm picking up properly through this course.

For the color palette I went with "Blue Eclipse" from Figma's color combinations library. It's a set of midnight blue tones (#272757, #8686AC, #505081, #0F0E47) that are described as conveying sophistication, with blue's calming quality and a sleek dark mode feel. Felt like the right fit for a tech portfolio.

I'm learning to think about design more intentionally. How layout, color, and type can do a lot of the work before a user even reads a single word.

02 / How I Work

Where I'm at

I don't have a formal design background. I'm taking SEG3125 to actually learn UI/UX properly instead of just winging it whenever I build a frontend. So far I've been figuring out how to think about layout and hierarchy before jumping into code.

What I'm learning

Visual hierarchy, scale, balance, contrast. Mostly through the course lectures and NN/g videos. Each case study is me trying to actually apply that stuff, not just read about it.

Tech stack

HTML, CSS, JavaScript, Bootstrap 5. I already know React and Node from other projects so the JS side isn't new. The design thinking side is what I'm here to actually develop.

As the semester goes on

This section will get updated as I finish each case study. I'll add notes on what design decisions I made and why, and what I'd probably do differently in hindsight.
