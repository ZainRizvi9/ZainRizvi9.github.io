02 / How I Work

Where I'm at

I don't have a formal design background. I'm taking SEG3125 to actually learn UI/UX properly instead of just winging it whenever I build a frontend. So far I've been figuring out how to think about layout and hierarchy before jumping into code.

What I'm learning

Visual hierarchy, scale, balance, contrast. Mostly through the course lectures and NN/g videos. Each case study is me trying to actually apply that stuff, not just read about it.

Tech stack

HTML, CSS, JavaScript, Bootstrap 5, and React for the last two case studies. I already knew React and Node from other projects so the JS side wasn't new. The design thinking side is what I was here to actually develop.

Looking back

Each case study pushed a different part of this: layout and content strategy for the service site, interaction design for the memory game, information architecture for the e-commerce site, and visualization plus internationalization for the dashboard.
